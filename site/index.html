> declarative audio for AI agents

Your agent writes the script as one YAML timeline. SonicCraft compiles it into TTS voices, music beds and sound effects: measured to the sample, ducked under every word, mastered to broadcast loudness, with subtitles that match the audio. A CLI, an MCP server and an Agent Skill.

$curl -fsSL https://raw.githubusercontent.com/user-github-me/soniccraft/main/install.sh | sh

01how it works

Intent goes in as data; SonicCraft does the geometry. Everything below is real output for this one timeline, rendered with the built-in mock voice: no API key needed.

1 write the timeline
~/episode — timeline.yaml
version: "1.0"
output: { path: episode.mp3, format: mp3, export_subtitles: [vtt, srt] }
speakers:
  host:  { provider: mock, voice_id: host }   # or elevenlabs, openai, kokoro, piper...
  guest: { provider: mock, voice_id: guest }
tracks:
  - id: voice
    type: speech
    start_at_ms: 1500
    sequence:
      - { speaker: host, text: "Welcome back to the show." }
      - pause: 300ms
      - { id: thanks, speaker: guest, text: "Thanks! Today: audio for AI agents." }
  - id: bed
    type: music
    source: music/bed.wav
    loop: true
    end_relative: { after_cue: thanks, offset_ms: 2000 }
    ducking: { trigger_tracks: [voice], reduction_db: -18 }

02errors an agent can fix

Every problem comes with a stable code, the exact line and column, and a hint. People read the text; agents get the same report as JSON with --json.

~/episode — zsh
$ soniccraft validate timeline.yaml
error[unknown_reference]: `after_cue` refers to `intr`, which is not the id of a cue, clip or track
  --> timeline.yaml:10:38
   |
10 |         start_relative: { after_cue: intr, offset_ms: "350 ms" }
   |                                      ^^^^
   |
   = hint: Did you mean `intro`? Known ids: `voice`, `intro`, `voice.cue2`, `bed`

03what's inside

A Rust engine built like a compiler: parse, lower, lay out, synthesize, mix, master.

  • [x]sample-accurate layoutevery clip measured; overlapping lines moved apart
  • [x]sidechain duckingmusic dips under each word, with attack, hold and release
  • [x]broadcast loudnessEBU R128 mastering, true-peak limiter, -16 / -14 LUFS presets
  • [x]word-timed subtitlesWebVTT, SRT, JSON word timings, HyperFrames transcripts
  • [x]free dry runslayout, ducking and cost before a single TTS call
  • [x]deterministicsame input, byte-identical audio; TTS results cached
  • [x]8 voice providersElevenLabs, OpenAI-compatible, Cartesia, Kokoro, Piper, macOS, command, mock
  • [x]outputsWAV, MP3, FLAC (OGG, Opus, M4A via ffmpeg), stems, manifest, web preview

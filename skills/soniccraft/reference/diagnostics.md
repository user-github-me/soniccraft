# SonicCraft diagnostics

Every problem SonicCraft finds is reported at once as a structured diagnostic. Codes are a stable API: key
your fixes on `code`, locate them with `path` (and `line`/`column` for YAML), and apply `hint` when present.

```json
{ "severity": "error", "code": "unknown_reference", "message": "...",
  "path": "tracks[2].sequence[0].start_relative.after_cue", "line": 37, "column": 21,
  "hint": "Did you mean `cue_01`? Known ids: cue_01, cue_02, cue_03", "related": ["cue_01"] }
```

- `severity`: `error` (the timeline cannot render), `warning` (it renders, but check this), `info`
  (what the engine did for you, e.g. `cue_pushed`).
- `path` uses `field.sub[index]` notation: `tracks[2]` is the third track, `sequence[0]` its first item.
- `related`: ids of the tracks, cues or clips involved.
- Hints are written to be applied mechanically: they name the field and write the value, and when a value
  has one obvious fix they convert it (`"350MS"` → `"350ms"`, `target_lufs: 16` → `-16`, `44.1k` → `44100`).
- Secrets are never repeated in a message, hint or path; CLI source snippets show them as `<redacted>`.

Repair loop: fix **every** error in one edit (they are independent), re-run `soniccraft validate`, repeat
until `valid: true`, then read warnings. CLI exit codes: `0` ok, `1` timeline invalid, `2` usage error, `3`
runtime or render failure (`130` interrupted). Over MCP an invalid timeline is still a successful
`validate`/`dry_run` call with `valid: false`; a failed render is a tool error (`isError: true`) carrying the
diagnostics.

Severities below are the usual ones; trust the `severity` field of each diagnostic. In `validate` and `plan`, a
layout error whose condition depends on estimated speech durations is reported as a warning ending in "(based
on estimated speech durations; the render checks again with exact durations)".

## Parse and schema

| Code | Severity | Meaning | Fix |
|---|---|---|---|
| `yaml_syntax` | error | The YAML does not parse: bad indentation, tabs used for indentation, an unquoted `: ` inside a value, a duplicate key, several documents in one file, more than 250000 values, or more than 64 levels of nesting. Also a document larger than 5 MB. An unquoted ` #` is not an error: it starts a comment and cuts the value short (in cue `text`/`caption` that is the `comment_in_text` warning). | Fix the text at `line`/`column`. Indent with spaces, quote strings containing `: ` or ` #`, keep one document, remove the duplicate key. Split a document that is too large into several timelines. |
| `json_syntax` | error | The JSON does not parse: trailing commas, comments (`//`, `/* */`, `#`: "JSON does not allow comments"), unquoted keys, duplicate keys, more than 250000 values or 64 levels of nesting (the same limits as YAML). | Fix at `line`/`column`. Delete comments (use an `x-note` key, or write the timeline as YAML) and trailing commas. On stdin and in MCP `yaml_content`, text starting with `{` is JSON unless it is YAML flow style (unquoted keys). |
| `invalid_type` | error | A value has the wrong type (`volume: "loud"`, `sample_rate: 44.1k`, a list where a mapping is expected, top-level `subtitles: true`). | Use the type named in the message. The hint converts recognisable values (`sample_rate: 44.1k` → `44100`, `volume: 50%` → `0.5`, `gain_db: "-6dB"` → `-6`, `channels: stereo` → `2`, `bit_depth: "24-bit"` → `24`; `subtitles: true` → `output: {export_subtitles: true}`). Other elements are still checked. |
| `unknown_field` | error | A key that is not allowed at this location: a typo (`fade_in`, `voice`, `triggers`), a synonym (`file`, `src` or `url` for `source`; `voice_name` for `voice_id`; `start_after: x`; `wait` or `pause_ms` for a pause), a key of another object (`label` on a track or cue), or `crossfade_ms` outside a `clips` entry. | Apply the hint: it names the DSL key and writes the value (`source: "..."`, `start_relative: {after_cue: x}`, `pause: 300`). Times are milliseconds: for a key without a unit (`duration: 30`) the hint says to write `"30s"` if you meant seconds. `label` belongs in a `speakers` entry. Use an `x-` prefix for your own annotations. |
| `missing_field` | error | A required field is absent: `version`, `tracks`, a track's `id` or `type`, a cue's `text`, a clip's `source`, `ducking.trigger_tracks`, or `type` on a provider instance with a custom name. `null` (a key without a value) counts as absent. | Add the field. For providers, either set `type:` or rename the instance to a built-in name. |
| `unsupported_version` | error (warning for a newer 1.x) | `version` is not a 1.x version, or names a 1.x newer than this SonicCraft (1.0). | `version: "1.0"`. |
| `invalid_value` | error | A value is out of range or not one of the allowed names: a bad enum (did-you-mean in the hint); an enum name with the wrong case or separators (`Speech`, `MP3`, `equal-power`: spellings are exact); an unparsable time (`"1,5s"`, `"soon"`); a time with uppercase units (`"350MS"`), clock seconds of 60 or more (`"1:99.5"`) or an exponent (`"1:1e2"`); a time above 24 h (usually epoch milliseconds); a time written as an id (`start_at_ms: a2`); a negative or zero length; `volume` above 4; `pan` outside [-1, 1]; `target_lufs` outside [-60, -5]; a positive loudness target (`target_lufs: 16`) or true-peak ceiling; a platform name as `loudness_preset` (`youtube`); `version: "01.0"`; a padded id; `trim_start_ms` beyond the source; an end before the start; an empty timeline (total length 0: only a looping bed and no tail). Engine cases: an output path that would overwrite something that is not a SonicCraft output (`notes.txt`, a directory where `ep.srt` goes), a timeline's own `output.path` outside the MCP server's base directory, and (warning) a `SONICCRAFT_MAX_RENDER_GB` that is not a positive number. | Use the value or form the hint gives; it converts the value (`"350ms"`, `target_lufs: -16`, `loudness_preset: streaming`, `start_relative: {after_cue: a2}`). Times: `350`, `"350ms"`, `"1.5s"`, `"1m30s"`, `"00:01:30.500"`. Empty timeline: give the looping bed a `fade_out_ms`, set `output.tail_ms` or `output.duration_ms`, or add content. Overwrite refusal: choose another output path or move the file away. |
| `field_not_applicable` | error (warning where noted) | A valid field on the wrong kind of object: clip fields (`source`, `loop`, fades, ...) on a speech track, `sequence`/voice fields on a music or sfx track. Warnings: `label` in `defaults` (ignored; `label` on a track or cue is `unknown_field`, and its hint points to a `speakers` entry); a voice key inside `settings` (`settings.voice` → `voice_id`, also `model`, `provider`, `language`); `crossfade_ms` on a clip that has its own `start_at_ms`/`start_relative` (ignored); a provider field its type does not use (`api_key_env` or `base_url` on command/piper/macos_say/mock, `voices_dir` outside piper, `command`/`stdin` outside command/piper). | Move the field where it belongs or delete it (e.g. put the music on its own `type: music` track; write `voice_id: nova` next to `settings`; remove `crossfade_ms` or the clip's own start). |
| `conflicting_fields` | error | Mutually exclusive fields together: `start_at_ms` + `start_relative`; more than one of `duration_ms` / `end_at_ms` / `end_relative`; pause and cue fields in one sequence item; shorthand clip fields and `clips` on one track; an anchor with zero or several of `after_cue` / `with_cue` / `before_cue`; `before_cue` in `end_relative`. | Keep exactly one. A pause is its own item: `- pause: 300ms`. With `clips`, move the clip fields into each clip. |
| `empty_tracks` | error | `tracks` is missing or empty. | Add at least one track. |
| `empty_sequence` | error | A speech track has no `sequence` items. | Add cues, or delete the track. |
| `empty_text` | error | A cue's `text` is empty after trimming. | Write the text, or turn the item into a pause. |
| `duplicate_id` | error | Two tracks, cues or clips share an id (one namespace for all three). | Rename one; update the anchors and `trigger_tracks` that refer to it. |
| `invalid_id` | error | An id is empty, contains whitespace (ids are not trimmed: `" v "`), or does not match `^[A-Za-z0-9_][A-Za-z0-9_.:-]*$`. | Use letters, digits, `_`, `.`, `:`, `-` (e.g. `cue_01`, `intro.music`). |
| `secret_in_timeline` | error | An API key or similar secret is in the document: a key named `api_key`, `apikey`, `token`, `secret`, `password` (also as an annotation, `x-api-key`), a key that looks like a provider key, a value like `sk-...`, or inside a `providers` entry or `settings` a key after `Bearer `, in `--api-key=...` or in a URL, a bearer token, a URL password (`https://user:pass@host`) or a secret URL parameter. Messages never repeat the secret. | Delete it. Export the key as an environment variable and, if it is not the default name, set `api_key_env: MY_VAR` on the provider instance (HTTP providers). A `command` program reads its own key from its environment. Rotate the leaked key. |
| `comment_in_text` | warning | An unquoted `text` or `caption` contains ` #`: YAML reads the rest of the line as a comment, so the cue speaks and captions only what comes before it (`Tip #1: ...` becomes `Tip`). | Quote the value; the hint has the exact line (`text: "Tip #1: always duck the music bed."`). If the `#` part is meant as a comment, put it on its own line. |
| `suspicious_value` | warning | A bare number that is almost certainly seconds written as milliseconds (`duration_ms: 30`, `fade_in_ms: 2`, `pause: 1.5`, `start_at_ms: 2.5`). Also (engine) a `command` template element that is `{text}` or `{voice_id}` on its own, so a text or voice id starting with `-` would be read as an option. | Write the unit (`duration_ms: "30s"`), or keep the value if you meant milliseconds. For command templates: pass text with `{text_file}` or `stdin: "{text}"`, and attach `{voice_id}` to its option (`--voice={voice_id}`, `-v{voice_id}`). |

## References

| Code | Severity | Meaning | Fix |
|---|---|---|---|
| `unknown_reference` | error | An anchor (`after_cue` / `with_cue` / `before_cue`) or `trigger_tracks` names an id that does not exist. | Use the hinted id (the hint lists known ids). Pauses cannot be referenced. Auto-generated cue ids are `<track_id>.cue<n>`; better, give the cue an explicit `id`. |
| `self_reference` | error | An item anchors to itself, or a track ducks from itself. | Point at another item or track. |
| `dependency_cycle` | error | Anchors form a loop, e.g. `cue_02 → cue_03 → cue_02` (the message lists it). A step through a track anchor names the item it resolves to (first declared item for with/before, last for after). A clip whose end waits for items anchored to its start is not a cycle. | Break one link: make one item sequential or absolute, or anchor it to a specific cue or clip outside the loop. |
| `anchor_open_ended` | error | An anchor needs the END of an item that has none: a looping clip without a length (it runs until the timeline end), or a track that ends with one. | Give the clip a length (`duration_ms`, `end_at_ms`, `end_relative`), or anchor to its start with `with_cue`, or anchor to the speech instead. |
| `unknown_provider` | error | `provider:` names neither a configured instance nor a built-in provider. | Use the hinted name, a built-in (`elevenlabs`, `openai`, `cartesia`, `kokoro`, `piper`, `macos_say`, `command`, `mock`), or add the instance under `providers:`. |
| `missing_provider` | error | A cue's voice resolves no provider at all. | Set `provider` in `defaults`, the speaker, the track or the cue. |
| `missing_voice` | error | The provider needs an explicit `voice_id` (elevenlabs, cartesia, piper, command) and none resolved. | Set `voice_id` on the speaker, track or cue. Find ids with `soniccraft voices <provider>`. |
| `unknown_speaker` | error or warning | A `speaker` is not a key of the (non-empty) `speakers` map. Error when it is a misspelling of a defined speaker (the hint names it; the cue's voice is checked as if you applied it); warning otherwise (it only works as a subtitle label). | Use the hinted speaker name, or add the speaker to `speakers`. |
| `default_voice` | info | No `voice_id` resolved; the provider's default voice is used (openai `alloy`, kokoro `af_heart`, macos_say `Samantha`, mock `mock`). | Set `voice_id` if you care which voice speaks. |
| `speakers_share_voice` | warning | Two or more speakers resolve to the same voice (provider, `voice_id`, model, settings), so they sound identical. Typical: two `mock` (or `openai`, `kokoro`, `macos_say`) speakers without a `voice_id`. | Give each speaker its own `voice_id` (mock: any string, e.g. `voice_id: alex` / `voice_id: sam`; others: run `soniccraft voices <provider>`). |

## Output settings

| Code | Severity | Meaning | Fix |
|---|---|---|---|
| `unsupported_sample_rate` | error | The rate is outside 8000 to 192000, or not an mp3 rate (8000, 11025, 12000, 16000, 22050, 24000, 32000, 44100, 48000) for mp3. | Use 48000 (default) or 44100. |
| `unsupported_bit_depth` | error | `bit_depth` not valid for the format (wav 16/24/32, flac 16/24). | Use 24 (default) or 16. |
| `bitrate_ignored` | warning | `bitrate` set for wav or flac. | Remove `bitrate`, or choose a lossy format. |
| `bitrate_adjusted` | info | The mp3 bitrate was rounded to the nearest LAME CBR rate. | Use a standard rate: 128k, 160k, 192k, 256k, 320k. |
| `format_extension_mismatch` | warning | `output.format` and the output path extension disagree; `format` wins, so the file holds that format's data under the other extension (e.g. `-o out.mp3` on a `format: wav` timeline writes WAV). | Make the extension match the format, or override the format too: CLI `--format mp3`, MCP `format: "mp3"`, or change `output.format`. |
| `format_requires_ffmpeg` | error | `ogg`, `opus` or `m4a` (or `mp3` in a build without the native mp3 encoder) needs ffmpeg, which is not on PATH. The message says where the format came from (`output.format`, the `output.path` extension, or a render option such as `--format`/`-o`). | Install ffmpeg, or use `wav` or `flac` (and `mp3` with the native encoder); for a render option, request another format or leave the option out. |

## Environment (checked by validate, plan and render)

| Code | Severity | Meaning | Fix |
|---|---|---|---|
| `asset_not_found` | error | A clip's `source` file does not exist (paths are relative to the timeline file). Checked even when the document has other errors. | Fix the path (the hint suggests close file names), or copy the file next to the timeline. |
| `asset_unreadable` | error | The file exists but cannot be decoded, or its sample rate is outside 1 to 768 kHz. | Convert it to wav, flac or mp3, or replace it; for a rate problem resample it (`ffmpeg -i input -ar 48000 output.wav`). |
| `missing_credentials` | error (warning when every cue of that provider is cached) | The provider's API key env var is not set, or holds an unexpanded placeholder such as `${ELEVENLABS_API_KEY}` (an MCP client passed its config template through). | `export ELEVENLABS_API_KEY=...` (or the provider's variable / `api_key_env`), switch those cues to a local provider, or render from cache. For a placeholder: remove the `env` entry from the MCP client config (stdio servers inherit the environment) or set the variable. |
| `provider_unavailable` | error (warning when every cue is cached) | The provider cannot run here: macos_say off macOS, a missing piper or command binary; a local server (Kokoro-FastAPI, an OpenAI-compatible server on this machine or network) that does not answer a 300 ms probe; an API key that would go to a host outside the key policy (not the provider's own API host, not this machine with the provider's own key variable, not in `SONICCRAFT_ALLOWED_HOSTS`); a `command` provider (or piper with its own `command`) on an MCP server started without `--allow-command`. | Install it, start the server (`docker run -p 8880:8880 ghcr.io/remsky/kokoro-fastapi-cpu:latest`), or switch to another provider (`mock` works everywhere). Host policy: if you trust the host, set `SONICCRAFT_ALLOWED_HOSTS=host` in soniccraft's environment (never in the timeline). MCP: restart the server with `soniccraft mcp --allow-command` only for timelines you trust. |
| `text_too_long` | error | A cue exceeds the provider's per-request character limit (e.g. OpenAI 4,096; ElevenLabs `eleven_v3` 5,000). | Split the cue into several cues at sentence boundaries (sequential cues play back to back). |
| `unknown_voice` | error (warning when every cue with that voice is cached) | The voice is not available here: a macOS voice that is not installed (`say` would silently use the default voice), or a piper model found in none of the searched directories. | Use the hinted voice (`voice_id: Samantha`; `soniccraft voices macos_say` lists installed voices). Piper: download the model with the command in the hint (`python3 -m piper.download_voices <name> --data-dir <dir>`), or set `voice_id` to the path of an `.onnx` model. |
| `suspicious_value` | warning | A `command` template element that is `{text}` or `{voice_id}` on its own (see Parse and schema). | Pass text with `{text_file}` or `stdin: "{text}"`; attach `{voice_id}` to its option. |
| `timeline_too_long` | error at render, warning in validate/plan | Rendering would need more memory than the render budget (`SONICCRAFT_MAX_RENDER_GB`, default 8 GB): about 23 MB per minute of stereo 48 kHz output, more with continuous speech, about 85 MB per minute for 24-bit FLAC. The render stops before synthesizing anything. | Split the timeline into several shorter ones (e.g. one per chapter), or raise the budget (`SONICCRAFT_MAX_RENDER_GB=16`) if the machine has the memory. |

## Layout (plan and render)

| Code | Severity | Meaning | Fix |
|---|---|---|---|
| `speech_overlap` | warning (error with `speech_overlap: error`) | Two speech cues overlap by more than `overlap_tolerance_ms` and the policy could not or would not resolve it (explicit cues are never moved, and an implicit cue is never pushed past an explicit cue anchored to it). The message names both cues, both intervals and the overlap. | Apply the hint: anchor the later cue, e.g. `start_relative: {after_cue: cue_02, offset_ms: 350}`, or set `allow_overlap: true` for intentional crosstalk. |
| `cue_pushed` | info | The `push` policy moved an implicit cue later to avoid an overlap: one per moved cue (from, to, the cue it waits for); after 50, one summary counts the rest. | Nothing to do if the order is what you want. To control it, anchor the cue explicitly. |
| `negative_start` | warning | A relative start resolved before 0 and was clamped to 0. | Reduce the negative `offset_ms`, or start the referenced item later (for `before_cue`, the hint gives the earliest start that fits). |
| `content_truncated` | warning | `output.duration_ms` cuts off content. | Raise `duration_ms` or remove it (the length is then automatic). |
| `clip_shorter_than_requested` | info | A non-looping clip's source ends before the requested length. | Set `loop: true`, use a longer file, or accept the natural length. |
| `fades_scaled` | info | `fade_in_ms + fade_out_ms` exceeded the clip length; both were scaled down. | Shorten the fades or lengthen the clip. |
| `no_fade_out_on_bed` | info | An open-ended (looping) bed has no `fade_out_ms`, so it stops abruptly at the end. | Add `fade_out_ms: 2500` (it also becomes the tail after the last word). |
| `muted_trigger` | info | A ducking trigger track is muted and is ignored for sidechain detection. | Unmute it, or remove it from `trigger_tracks`. |
| `track_anchor_out_of_order` | warning | An anchor on a track resolves to its first declared item (`with_cue`/`before_cue`) or its last declared item (`after_cue`), but another item of that track starts earlier or ends later (an item with its own start, declared out of order). | Anchor to that item instead (`with_cue: intro` / `after_cue: outro`), or reorder the track's items so the first one starts first and the last one ends last. |
| `timeline_too_long` | error | The timeline would be longer than 24 h (its content, the tail, or `output.duration_ms`). The message names the item that ends last. | Move the named item earlier or shorten the content; lower `output.tail_ms` or the bed's `fade_out_ms`; look for a `start_at_ms`, `offset_ms` or pause written in seconds or minutes but meant in milliseconds. |

## Render

| Code | Severity | Meaning | Fix |
|---|---|---|---|
| `synthesis_failed` | error | The provider rejected or failed a request (bad key, unknown voice, quota, network after retries). The message carries the provider's error and a reason code: `connect_failed` (nothing answered; local servers are not retried), `not_attempted` (an earlier cue found the server unreachable), `deadline_exceeded` (`timeout_ms` passed, retries included), `response_too_large`, `implausible_duration` (far more audio than the text can produce: wrong `base_url` or `output_format`), `redirect_refused` (redirects are never followed), `option_like_argument` (a `command` would read the cue text or voice id as an option), `key_host_not_allowed`, `placeholder_key`. | Follow the hint: check the env var, list voices with `soniccraft voices <provider>`, lower `max_concurrency` on rate limits, start the local server, raise `timeout_ms`, fix `base_url`, pass text via `{text_file}`/stdin, or switch provider. Cached cues are not re-billed on retry. |
| `normalization_skipped` | info | A source was too short or quiet to measure; it was left at its own level. | Usually fine (very short words, near-silent files). Adjust that item's `volume` if needed. |
| `loudness_target_unreachable` | warning | Reaching `target_lufs` would need more than 6 dB of average limiting. The master is the loudest the mix allows within that limit, whatever the target; the message gives the achieved value. | Set `output.target_lufs` to the achieved value from the message (or lower), raise `true_peak_db` slightly, or turn down dense music and loud transients (e.g. sfx `volume`). |
| `loudness_target_missed` | warning | Mastering stopped outside 0.2 LU of a reachable target after 4 limiter passes (the loudness jumps where quiet passages cross the BS.1770 gate), or keeping a lossy file under the true-peak ceiling cost more than 0.2 LU. The closest pass was kept. | Accept the level (set `output.target_lufs` to the achieved value in the message), or even out the mix (raise quiet passages, lower loud transients). For lossy formats: lower the target, raise `output.bitrate`, or deliver wav/flac. |
| `true_peak_exceeded` | warning | The encoded mp3/ogg/opus/m4a file still peaks above `true_peak_db` after 2 compensation passes (codecs reshape peaks). | Lower `output.true_peak_db` (e.g. `-2.0` for lossy delivery), raise `output.bitrate`, or deliver `wav`/`flac`. |
| `silent_output` | warning | The master is silent (nothing audible was mixed); no gain applied. | Check `mute`, volumes, and that tracks have content within the timeline length. |
| `alignment_estimated` | info | The provider returns no word timings; subtitle word times were estimated from the audio. | Fine for most captions. For word-accurate captions use elevenlabs, cartesia, kokoro or mock. |
| `encode_failed` | error | Writing the output failed (disk, permissions, ffmpeg error), or the outputs could not be put in place ("every output was left as it was before this render"). | Check the output directory and free space; for ogg/opus/m4a check ffmpeg; make sure no other process writes the same files. |
| `decode_failed` | error (warning where noted) | Provider audio or a source file could not be decoded at render time (also an unsupported sample rate). Warning: the encoded lossy file could not be decoded to check its loudness (the report then shows the master), or an MP3 stream continues past the length its header announces. | Re-render with `--no-cache` for provider audio; convert, resample or replace the source file. |
| `cache_write_failed` | warning (once per render) | The TTS cache could not be written (read-only directory, full disk); the render succeeded, but later renders will synthesize those cues again. Left out of the manifest and preview. | Make the cache directory writable, or pass `--cache-dir` / set `SONICCRAFT_CACHE_DIR` to a writable directory. |
| `audio_repaired` | warning | A source file or cache entry contained non-finite samples (NaN, ±∞); they were replaced with silence. | Re-export the file as 16- or 24-bit PCM (`ffmpeg -i in.wav -c:a pcm_s24le fixed.wav`) and point `source` at it; for a cache entry, render with `--no-cache`. |
| `channels_downmixed` | info | A source with more than two channels (5.1, 7.1) was mixed down to stereo with ITU-R BS.775 (LFE dropped). | Nothing needs to change; to control the downmix, export a stereo file (`ffmpeg -i in.wav -ac 2 out.wav`). |
| `setting_ignored` | info | A provider ignored or replaced a setting (e.g. `eleven_v4` has no `style`/`speed`; a plan without `pcm_44100` falls back to `pcm_24000`), or a `settings` key the provider does not read ("macos_say ignores `voice`; it reads `rate`, `speed`"). | Usually fine. Remove the setting, or pick a model that supports it; choose the voice with `voice_id`, never `settings.voice`. |
